\subsection{Scopes and Public Events}

\hspace*{\parindent}\textbf{Sports} uses participant activity and availability contexts for optional walking and everyday physical-activity assistance.

\textbf{Home} uses time-bounded home-sensor observations for gentle, low-risk check-ins.
Each sensor segment becomes available at interval closure.

\textbf{Code} uses repository activity at GitHub's native event granularity for low-risk triage, review, and maintenance, with one decision per event.

Each participant, home, or repository defines an isolated chronological stream, allowing earlier observations to inform later service opportunities.
Public inputs contain contemporaneously available observations, using the same scope-specific schema for both label classes.
Agents construct their own memory from these events; annotation and scoring metadata remain evaluator-private.
Appendix~\ref{app:benchmark_protocol} details source datasets, fields, and preprocessing.

\subsection{Reference Labels and Causal Replay}
\label{sec:reference_labels}

Annotators assess $e_t$ and its complete prior same-stream history $\mathcal{H}_{<t}$.
Let $A$ indicate a concrete, timely, feasible, low-risk opportunity supported by $e_t$, $B$ an opportunity at $e_t$ supported by historical observations, and $N_t^{\mathrm{ref}}$ reference-episode novelty:
\begin{equation}
\begin{aligned}
y_t=1 \quad \Longleftrightarrow \quad &
\big(A(e_t)=1\ \lor\ B(e_t,\mathcal{H}_{<t})=1\big)\\
&\land N_t^{\mathrm{ref}}=1.
\end{aligned}
\label{eq:or_semantics}
\end{equation}
The reference protocol labels the first reliable actionable window \textsc{Intervene} and covered windows \textsc{Abstain}, allowing renewed opportunities when support strengthens, the service changes, or an episode reopens.
Reference novelty follows the reviewed opportunity sequence independently of model outputs and is shared across methods.
The event-level labels therefore assess timely identification of reviewed service windows.

LLM-assisted screening prioritizes candidate opportunities; three team members then independently label every event while blinded to evaluated-system outputs, followed by cross-review and adjudication.
For a separate-team review, a fixed SHA256 rule selects one stream and 150 contiguous targets per scope from public metadata, requiring at least seven days of prior history and retaining each complete causal prefix.
Three reviewers label these 450 targets with model outputs hidden and form consensus references.
Agreement with earlier references is 88.7\%, 91.3\%, and 85.3\% for Sports, Home, and Code; these references do not replace the main labels.
Section~\ref{sec:reviewed_diagnostics} reports paired rescoring of fixed diagnostic outputs.
Main comparisons use protocol-fixed evaluation on the jointly developed benchmark, with labels, prompts, memory bounds, and validation settings frozen before the corresponding runs.

Each stream is replayed chronologically from empty method state, with access to the current event and strictly prior same-stream context.
Each decision is finalized before the current event is committed to memory; reference labels are joined after inference for scoring.
Scoring includes the initial events and continues as history accumulates.
