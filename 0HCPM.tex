\begin{abstract}
Proactive LLM agents must decide whether a newly observed event warrants unsolicited assistance, even when relevant evidence is distributed across earlier observations.
Existing event-history and retrieval interfaces preserve prior information but leave the agent to distinguish recent facts, recurring temporal structure, and present service value at decision time.
We introduce ProactiveStream, a longitudinal benchmark spanning Activity Support, Ambient Living, and Repository Assistance, with 4,539 inference events from 17 isolated streams.
We further propose Event-Driven Proactive Memory (\system{}), which organizes each stream into bounded Event Memory, fact-validated Daily Trajectory Memory, and replay-validated Temporal Pattern Memory, and selects evidence applicable to the current decision.
Across the three settings, Full \system{} improves Intervention F1 over ProactiveAgent by 4.8--28.5 points and also outperforms Mem0.
Controlled hierarchy and validation ablations further support the contribution of validated daily and temporal-pattern evidence.
These results frame proactive memory as a validated evidence lifecycle rather than an unconstrained history archive or an implicit intervention policy.
\end{abstract}
