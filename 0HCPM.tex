\begin{abstract}
Proactive LLM agents must decide whether a newly observed event warrants unsolicited assistance.
The evidence for that decision may be absent from the current event and distributed across days, yet exposing an ever-growing event history leaves temporal structure implicit and increases context cost.
We present Event-Driven Proactive Memory (\system{}), a hierarchical memory that progressively transforms an entity-isolated event stream into three evidence levels: bounded source-level evidence in Source Memory, fact-validated daily trajectories in Working Memory, and replay-validated long-term trajectories in Long-term Memory.
Daily validation asks whether an extracted fact is supported by source events; historical replay asks whether a proposed temporal structure recurs; the decision LLM then proposes whether the current event itself \emph{or} memory evidence creates a concrete, timely, and low-risk opportunity to Push.
We construct a label-hidden benchmark of 3,080 decisions from 9 HeartSteps participants and 4 CASAS homes, with 423 entity-days and 13 strictly isolated streams; reference labels and all annotation metadata remain evaluator-private.
The episode-aware reference labels encode reviewed service opportunities and are frozen after LLM-assisted screening, independent annotation by three team members conducted in parallel with but isolated from model inference, cross-review, and adjudication.
Using a common backbone model, with an identical decision prompt across the three \system{} variants, Full \system{} achieves 39.2\% precision, 75.7\% recall, and 51.7\% micro F1.
It exceeds ProactiveAgent-Prompt by 10.5 F1 points while reducing Push rate by 2.7 points, and exceeds Source-only and Source+Working by 12.9 and 11.0 F1 points.
Offline audits further show that all 1,279 retained daily episodes are source-supported; all 54 retained long-term proposals are source-linked and replay-audited, and 42 meet the Active gate.
These results show that validated temporal abstraction can make proactive decisions both more informed and more selective without turning memory itself into a hidden intervention rule.
\end{abstract}
