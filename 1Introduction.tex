\section{Introduction}
\label{sec:introduction}

An activity record, a home-sensor update, or a repository change may warrant assistance before a user asks for it.
Yet a similar observation may require no action: its significance depends on prior events and whether the opportunity has already been addressed.
Event-driven LLM agents must therefore judge not only what an event means, but whether it warrants intervention now.

Agent memory systems retain observations, consolidate experience, and retrieve related information~\citep{park2023generative,packer2023memgpt,chhikara2025mem0}.
Recent work also studies history-based intervention judgment and proactive memory use~\citep{lu2025proactiveagent,xie2026pask,li2026memcog,wu2026remember}.
These capabilities make historical information available, but its use for intervention requires three distinct judgments: whether an abstraction reflects its source events, whether a proposed temporal pattern has recurring support, and whether it applies now.
A similar past event alone establishes neither recurrence nor a present service need.
The central question is thus \emph{how to turn retained history into evidence for a timely intervention}, rather than simply how much history to retain.

We propose Proactive Evidence Memory (\system{}; Figure~\ref{fig:architecture}) to separate evidence construction from intervention judgment.
Bounded Event Memory preserves recent observations; source-checked Daily Trajectory Memory retains evidence beyond that window; Temporal Pattern Memory captures recurring conditions assessed through historical replay.
At decision time, the agent combines event and daily evidence with currently applicable patterns.
Either the current event or historical evidence may support a concrete, timely, low-risk service; recurrence is neither required nor an instruction to intervene.
Episode control then checks whether the proposed opportunity has already been covered.

We evaluate \system{} on \emph{ProactiveStream}: 4,539 events from 17 isolated streams across Activity Support, Ambient Living, and Repository Assistance.
Under causal replay, it improves Intervention F1 by 4.3--11.5 percentage points over the strongest baseline in each scope, among ProactiveAgent, Mem0, Cross-week Summary Memory (CSM), and Graphiti.
Hierarchy and validation ablations examine the contribution of evidence organization and checks beyond history retention alone.

Our contributions are:
\begin{itemize}
    \item \textbf{Method.} An evidence lifecycle separating source fidelity, historical support, and current applicability from intervention judgment.
    \item \textbf{Evaluation platform.} ProactiveStream supports causal, entity-isolated evaluation with episode-aware reference opportunities across three service scopes.
    \item \textbf{Empirical analysis.} Memory-interface comparisons, targeted ablations, and behavioral diagnostics characterize the contributions and limits of the proposed lifecycle.
\end{itemize}
