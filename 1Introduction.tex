\section{Introduction}
\label{sec:introduction}

Proactive LLM agents anticipate useful assistance as a user's situation evolves, taking initiative before an explicit request.
Recent systems study when to propose a task, detect emerging needs, and use contextual or historical information to guide that judgment~\citep{lu2025proactiveagent,yang2025contextagent,xie2026pask,li2026memcog}.
In activity support, ambient living, and repository maintenance, this requires interpreting a continuing stream of observations and deciding whether a service opportunity warrants attention now.

Historical context is central to this decision.
Figure~\ref{fig:intro_scenario} illustrates how earlier evening walks can inform a service judgment when current activity is low and the user is available.
Daily trajectories and temporal patterns retain this context beyond a recent-event window.
The agent must connect that history to a concrete, timely service.

Agent memory systems retain observations, consolidate experience, and retrieve related information~\citep{park2023generative,packer2023memgpt,chhikara2025mem0,xu2025amem}.
To turn this history into decision context, proactive agents must assess whether an abstraction reflects its source events, whether a proposed temporal pattern has recurring support, and whether that pattern applies now.
Our central question is \emph{how to turn longitudinal history into reliable, currently applicable context for proactive service decisions}.

We propose Proactive Evidence Memory (\system{}; Figure~\ref{fig:architecture}), a hierarchical memory framework that organizes event histories into source-checked daily trajectories and replay-assessed temporal patterns for proactive service decisions.
Bounded Event Memory preserves recent observations, while Daily Trajectory Memory retains source-checked abstractions beyond the recent window.
Temporal Pattern Memory consolidates recurring conditions from these daily trajectories and assesses their historical support through replay.
At decision time, the agent combines recent events and daily trajectories with currently applicable patterns.
The decision LLM assesses whether current observations or historical context support a concrete, timely, low-risk service; episode control tracks whether the proposed opportunity has already been covered.

We construct \emph{ProactiveStream} to study these decisions over 4,539 events from 17 isolated streams.
Its three scopes preserve causal history and define episode-aware reference opportunities, allowing evaluation of memory formation and repeated service decisions within the same streams.
\system{} improves Intervention Score (IS) by 4.3--11.5 percentage points over the strongest comparator in each scope, among five external baselines and a recursive-summary control.
Hierarchy and validation ablations examine how historical organization and support checks contribute to these gains.

Our contributions are:
\begin{itemize}
    \item \textbf{Method.} \system{} combines source-checked daily abstraction, replay-based pattern assessment, and selection of currently applicable patterns to supply historical context for proactive service decisions.
    \item \textbf{Benchmark.} ProactiveStream supports longitudinal evaluation of memory formation and repeated service decisions, preserving causal history, entity isolation, and episode-aware reference opportunities across three scopes.
    \item \textbf{Empirical findings.} \system{} achieves higher IS than the evaluated baselines and summary control in all three scopes; targeted ablations support the contributions of hierarchical organization and validation.
\end{itemize}
