\section{Introduction}
\label{sec:introduction}

Proactive LLM agents anticipate useful assistance as a user's situation evolves, taking initiative before an explicit request.
Recent systems study when to propose a task, detect emerging needs, and use contextual or historical information to guide that judgment~\citep{lu2025proactiveagent,yang2025contextagent,xie2026pask,li2026memcog}.
Across our Sports, Home, and Code scopes, this requires interpreting a continuing stream of observations and deciding whether a service opportunity warrants attention now.

Historical context is central to this decision.
Figure~\ref{fig:intro_scenario} illustrates how earlier evening walks can inform a service judgment when current activity is low and the user is available.
The temporal trajectories and behavioral regularities retain this context beyond a recent-event window.
The current event guides regularity matching, and retrieved memory informs the service decision.

Agent memory systems retain observations, consolidate experience, and retrieve related information~\citep{park2023generative,packer2023memgpt,chhikara2025mem0,xu2025amem}.
To turn this history into decision context, proactive agents must assess whether an abstraction reflects its source events, whether a proposed behavioral regularity has recurring support, and whether that regularity applies now.
Our central question is \emph{how to turn longitudinal history into reliable, currently applicable context for proactive service decisions}.

We propose Proactive Memory (\system{}; Figure~\ref{fig:architecture}), a hierarchical memory framework that organizes event histories into source-checked temporal trajectories and replay-assessed behavioral regularities for proactive service decisions.
The bounded event memory preserves recent observations, while temporal trajectory memory retains source-checked abstractions beyond the recent window.
The behavioral regularity memory consolidates recurring conditions from these temporal trajectories and assesses their historical support through replay.
At decision time, the agent combines recent events and temporal trajectories with currently applicable regularities.
The decision LLM assesses whether current observations or historical context support a concrete, timely, low-risk service; intervention control tracks whether the proposed opportunity has already been covered.

We construct \emph{ProactiveStream} to study these decisions over isolated longitudinal event streams.
Its three scopes preserve causal history and define episode-aware reference opportunities, allowing evaluation of memory formation and repeated service decisions within the same streams.

Our contributions are:
\begin{itemize}
    \item \textbf{Method.} \system{} combines source-checked trajectory abstraction, replay-based regularity assessment, and selection of currently applicable regularities to supply historical context for proactive service decisions.
    \item \textbf{Benchmark.} ProactiveStream supports longitudinal evaluation of memory formation and repeated service decisions, preserving causal history, entity isolation, and episode-aware reference opportunities across three scopes.
    \item \textbf{Empirical findings.} \system{} achieves higher event-level effectiveness and balance than the evaluated external baselines in all three scopes; targeted ablations support the contributions of hierarchical organization and validation.
\end{itemize}
