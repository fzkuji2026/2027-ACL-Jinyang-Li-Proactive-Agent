LLM agents are evolving from executing user-specified tasks toward proactive assistance that identifies service opportunities from ongoing observations and historical experience before an explicit request.

Existing work advances this goal through proactive decision-making and memory organization.
ProactiveAgent learns proactive task proposals from activity contexts~\citep{lu2025proactiveagent}, while ContextAgent combines sensed context with historical personas to assess service needs~\citep{yang2025contextagent}.
Mem0 extracts, consolidates, and retrieves important information~\citep{chhikara2025mem0}; A-MEM organizes historical knowledge through dynamically linked notes~\citep{xu2025amem}.
For evaluation, ProactiveBench and ContextAgentBench focus on proactive task proposals and context-aware service, respectively, while LoCoMo and LongMemEval study memory and reasoning over long-term conversations~\citep{maharana2024locomo,wu2025longmemeval}.
Continuous proactive assistance calls for joint evaluation of memory accumulation, present applicability, and changes in service-opportunity state within the same event stream.
This raises a central question: \emph{how can accumulated history be organized into source-grounded, recurrently supported, and currently applicable memory to support timely and selective proactive assistance?}

To study this question, we construct \emph{ProactiveStream}, a longitudinal event-stream benchmark spanning Sports, Home, and Code.
The benchmark preserves chronological order and isolated histories for each participant, home, and repository.
Agents build their own memory as events arrive and make sequential decisions around the first actionable window of a service opportunity and its subsequent state changes.
Under a shared backbone and intervention control policy, existing proactive-service and memory-enhanced methods exhibit different trade-offs between opportunity recovery and false-intervention control (Table~\ref{tab:main_results}), highlighting the need to connect historical information with current service judgments.
Figure~\ref{fig:intro_scenario} illustrates how earlier evening walks can complement the current event in assessing a service opportunity.

To establish this connection, we propose Proactive Memory (\system{}; Figure~\ref{fig:architecture}), a hierarchical memory framework linking recent observations, temporal activities, and recurring behavior.
Event memory preserves fine-grained recent evidence, temporal trajectory memory organizes historical events into source-grounded activity representations, and behavioral regularity memory captures historically supported conditional behavior.
These complementary representations connect immediate changes with long-term behavioral context, allowing proactive service decisions to draw on evidence at different temporal scales.

During memory construction, LLMs organize completed historical events into temporal trajectories with source citations, and a validator checks the extracted typed facts against their source events.
Conditional behavioral regularities are then inferred from these trajectories and assessed for recurring support through historical replay.
At decision time, the current event guides matching and retrieval of applicable regularities, and the decision LLM combines recent events, temporal trajectories, and retrieved regularities to assess present service value.
Intervention control tracks previously covered service opportunities and filters repeated proposals.
The current event is committed to memory after the decision is finalized, providing context for subsequent events.

Our contributions are:
\begin{itemize}[leftmargin=*, itemsep=0pt]
    \item ProactiveStream supports longitudinal evaluation of memory formation and repeated service decisions, preserving causal history, entity isolation, and episode-aware reference opportunities across three scopes.
    \item \system{} combines source-checked trajectory abstraction, replay-based regularity assessment, and selection of currently applicable regularities to supply historical context for proactive service decisions.
    \item \system{} uses long-term behavioral context to identify service opportunities missed by recent events alone and support more selective intervention decisions.
\end{itemize}
