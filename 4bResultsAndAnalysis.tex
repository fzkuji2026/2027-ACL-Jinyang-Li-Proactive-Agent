\paragraph{\mdseries Comparisons with external methods.}
Against A-MEM, \system{} recovers more opportunities with fewer false interventions in every scope.
However, Mem0 has higher Sports Coverage, and some methods attain lower Home/Code FPR with lower Coverage.
IR combines recovered opportunities and false interventions; lower frequency alone does not imply better decisions.

\paragraph{Reference sensitivity.}
\label{sec:reviewed_diagnostics}
Rescoring fixed \system{} outputs from a separate 450-target diagnostic against the earlier and separate-team references (Section~\ref{sec:reference_labels}) changes Effectiveness from 42.6\% to 42.5\% on Sports, 68.7\% to 55.6\% on Home, and 57.6\% to 47.4\% on Code.
Absolute scores are label-sensitive, especially on Home and Code.

\paragraph{Episode-level analysis.}
A model-assisted post-hoc analysis on those targets reconstructs 67 goal-and-object episodes from 76 positive event anchors.
First timely matching assistance covers an episode; repetition without actionable new evidence is redundant.
\system{} covers 23/26 Sports episodes, 10/10 Home episodes, and 14/31 Code episodes.
Its redundant-intervention shares are 1.2\%, 43.6\%, and 9.5\%, respectively: full Home coverage coexists with 17 redundant interventions out of 39, while Code leaves 17 reference episodes uncovered.
Episode-level analysis complements event-level evaluation by measuring opportunity coverage and repeated interventions.
Appendix~\ref{app:label_review_450} retains reference-sensitivity scores and episode-matching records.

\subsection{Ablation Study and Memory Analysis}
\label{sec:hierarchy}
\label{sec:validation_ablations}

\paragraph{Memory levels.}
Event-only supplies current and bounded recent events; Event+Daily adds source-checked daily trajectories; \system{} adds temporal patterns.
These three variants in Figure~\ref{fig:memory_hierarchy} share Luna, decision prompt, schema, event bound, and controller.
The controller uses representation-dependent keys, so the comparison measures memory-layer contributions within the implemented pipeline.
Daily trajectories recover more opportunities, most on Code, with unchanged Sports/Home false-positive counts and two additional Code false positives.
Patterns further increase Effectiveness by 9.9/13.5/7.0 points (Sports/Home/Code), increasing true positives and reducing false positives (RQ2).
Daily abstraction expands context; supported, currently applicable patterns improve selectivity.

\paragraph{Validation mechanisms.}
Table~\ref{tab:validation_ablations} fixes model, prompt, event bound, context capacity, and controller.
\emph{w/o Replay Gate} bypasses activation thresholds for well-formed, source-linked, online-reconstructable Candidates, retaining current-applicability matching.
\emph{w/o Daily Validation} stores schema-valid, same-entity daily extractions without fact checking, retaining weekly construction and replay.
Both removals lower Relevance and Effectiveness (RQ3).
Replay gating contributes more Effectiveness and improves Coverage in every scope.
On Code, daily validation removes 43 false interventions without losing true positives, supporting improved selectivity.
