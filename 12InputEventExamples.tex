\subsection{Example input events}
\label{app:input_event_examples}

Figure~\ref{fig:input_event_examples} shows one public event record from each scope of ProactiveStream.
Field names, values, and nesting are retained; additional fields are omitted for readability.
Events are processed chronologically within each stream, and reference labels are stored separately for evaluation.

\begin{lstlisting}[style=inputevent]
{
  "decision_id": "casas50_d_000000",
  "stream_id": "casas_home_0001",
  "window_start": "2012-07-21T00:00:00",
  "window_end": "2012-07-21T00:50:00",
  "decision_time": "2012-07-21T00:50:00",
  "duration_minutes": 50,
  "motion": {
    "raw_event_count": 84,
    "activation_count": 43,
    "deactivation_count": 41,
    "location_counts": {
      "Bathroom": 13,
      "Bedroom": 17,
      "LivingRoom": 11,
      "OutsideDoor": 2
    },
    "location_sequence": [
      "Bedroom", "LivingRoom", "OutsideDoor",
      "Bedroom", "Bathroom", "Bedroom"
    ]
  },
  "door_actions": [],
  "numeric_sensors": [],
  "other_actions": []
}
\end{lstlisting}
This event summarizes sensor observations from 00:00 to 00:50 in source-local time and becomes available when the interval closes at 00:50.
Location counts record sensor activations; the location sequence collapses consecutive repeated location labels.
\end{minipage}
