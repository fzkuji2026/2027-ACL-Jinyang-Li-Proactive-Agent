\section{Problem Formulation}
\label{sec:problem}

Let $u$ denote an isolated entity with a time-ordered public event stream
\begin{equation}
E^u=(e^u_1,\ldots,e^u_{T_u}), \qquad
e^u_t=(\tau^u_t,x^u_t),
\label{eq:event_stream}
\end{equation}
where $T_u$ is the number of events for entity $u$, $\tau^u_t$ is the event time, and $x^u_t$ contains the scope-specific public fields observable at that time.
We omit the entity superscript $u$ when it is unambiguous.
Before processing $e^u_t$, an agent has a causal state $Z^u_t$ constructed only from events and finalized outputs preceding $\tau^u_t$.
It produces
\begin{equation}
(\hat y_t,\hat m_t)=\pi(e^u_t,Z^u_t),
\qquad \hat y_t\in\{0,1\},
\label{eq:generic_decision}
\end{equation}
where $\hat y_t=1$ denotes \textsc{Intervene}, $\hat y_t=0$ denotes \textsc{Abstain}, and $\hat m_t$ is an optional evidence-grounded service message.
Here $\pi$ denotes a general inference policy over the current event and causal state; $\hat m_t$ may be empty under \textsc{Abstain}.
The event is committed only after the output is finalized:
\begin{equation}
Z^u_{t+1}=U(Z^u_t,e^u_t,\hat y_t,\hat m_t).
\label{eq:causal_update}
\end{equation}
No state is shared across entities, and neither future events nor evaluator-private information is available to $\pi$.

The target is a reviewed \emph{service opportunity}, rather than unusual behavior alone.
Let $y_t\in\{0,1\}$ denote the frozen, reviewed reference label for event $e_t$.
The objective is to identify timely, actionable service opportunities supported by the current event or strictly prior same-entity observations.
Reference labels are defined independently of the evaluated agent's state representation; the annotation criteria are specified in Section~\ref{sec:reference_labels}.

At inference time, $\pi$ observes only the current scope-specific public event fields and causally available state from the same entity.
The frozen reference labels and annotation metadata remain evaluator-private, and intervention and abstention events share the same scope-specific public schema.
