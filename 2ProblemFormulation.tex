\section{Problem formulation}
\label{sec:problem}

Each participant, household, or repository $u$ has an isolated public event stream
\begin{equation}
E^u=(e^u_1,\ldots,e^u_{T_u}), \qquad
e^u_t=(\tau^u_t,x^u_t),
\label{eq:event_stream}
\end{equation}
where $T_u$ is the stream length and $x^u_t$ contains public fields available at time $\tau^u_t$.
Events follow chronological order with deterministic tie-breaking; we omit $u$ when clear.
State $Z^u_t$ comprises prior same-entity observations, finalized outputs, and the memory and intervention-control states derived from them.
The policy produces
\begin{equation}
(\hat y_t,\hat m_t)=\pi(e^u_t,Z^u_t),
\qquad \hat y_t\in\{0,1\},
\label{eq:generic_decision}
\end{equation}
where $\hat y_t=1$ denotes \emph{intervene}, $\hat y_t=0$ denotes \emph{abstain}, and $\hat m_t$ is an optional evidence-grounded service message.
After finalization, update function $U$ commits the event and output:
\begin{equation}
Z^u_{t+1}=U(Z^u_t,e^u_t,\hat y_t,\hat m_t).
\label{eq:causal_update}
\end{equation}
The objective is to detect timely, actionable \emph{service opportunities} supported by current or prior same-entity observations.
Evaluation uses fixed reference decisions $y_t\in\{0,1\}$ under Section~\ref{sec:reference_labels}; labels and annotation metadata remain evaluator-private.
