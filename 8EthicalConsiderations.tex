\section*{Ethical considerations}

Our evaluation is limited to optional activity support, gentle check-ins, and low-risk repository assistance.
Medical and high-risk safety decisions require separate domain-specific validation and safeguards.
Inference is isolated by stream, and reference labels, episode annotations, and scoring metadata are excluded from model inputs.

Longitudinal events and derived memories can reveal sensitive routines even when identifiers are pseudonymized.
Event content, prediction traces, and inferred trajectories require access and retention protections; external-model use should minimize transmitted information and respect source-data permissions.

Deployment should require informed opt-in and allow inspection, correction, deletion, retention control, and disabling proactive assistance.
An intervention prediction represents a service proposal; consequential action requires separate authorization.
These deployment safeguards require separate implementation and evaluation.
