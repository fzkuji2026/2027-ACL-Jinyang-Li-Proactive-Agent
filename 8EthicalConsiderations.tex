\section*{Ethical Considerations}

Proactive memory can infer recurring temporal structure that a user never explicitly chose to store.
Activity schedules and household movement can be sensitive even when each event is individually innocuous.
A deployment should require informed opt-in, entity-scoped access control, visible inspection of inferred trajectories, correction and deletion controls, retention limits, and a global way to disable proactive behavior.
Memories must not be silently transferred across participants, homes, applications, or accounts.

Incorrect intervention can be intrusive or harmful.
The CASAS task permits only gentle low-risk check-ins and prohibits disease, fall, travel, danger, and preference inference.
HeartSteps opportunities are optional activity support, not medical recommendations or estimates of treatment effect.
High-impact decisions require domain policy checks and explicit human confirmation beyond the architecture evaluated here.

The benchmark maintains a strict public/private boundary.
Reference labels, screening outputs, review stages, episode annotations, and scoring masks are never included in agent input.
Participant and home identifiers are pseudonymized at the stream level, and all inference is entity-isolated.
Model-visible payloads sent to an external API contain no organizer-private label or credential.
Prediction traces, daily trajectories, and long-term trajectories should nevertheless receive the same retention and access protections as the source streams.
